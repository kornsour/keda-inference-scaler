# Archive

This folder holds historical and superseded documentation and records from this
project: old plans, prior design notes, retired decisions, and other material that
was once relevant but has since been replaced or overtaken by events.

Nothing in this folder reflects the current state of the project. It exists purely
as a record of what was decided, proposed, or true at some point in the past.

**Do not use anything under `archive/` to understand how the project currently works,
what its current design or configuration is, or what to do next.** If you are a
contributor or a coding agent looking for guidance, treat every file here as
historical context only — never as current truth. Always prefer the top-level
README and any current docs outside this folder.
